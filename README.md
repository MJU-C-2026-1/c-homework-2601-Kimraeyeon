# 💻 [2026-01] 나만의 C언어 소프트웨어 개발 프로젝트

## 1. 시나리오 제목
* 알바비 정산 확인 프로그램 

<br>


## 2. 시나리오 (5~10줄)
* 이 프로그램은 아르바이트생의 근무 정보를 입력받아 세금 공제 전후의 알바비를 정확히 계산하고 명세서를 발급하는 '종합 급여 정산 시스템' 입니다.
* 사용자는 근무 조, 시급, 일한 시간, 적용 세금 비율 등의 기본 데이터를 입력합니다. 시스템은 이를 바탕으로 총 급여와 세후 실수령액을 계산하여 출력합니다. 향후에는 조건문을 활용해 근무 조(주간/야간)나 초과 근무에 따른 수당 할증을 계산하고, 메뉴를 통해 주휴수당 계산, 세금 종류 선택 등의 기능을 추가할 예정입니다. 최종적으로는 여러 명의 알바생 데이터를 동시에 관리하고 조회할 수 있는 완성도 높은 매장용 급여 관리 시스템을 구축할 계획입니다.

<br>


## 3. 예상 기능 및 메뉴 (최소 5개)
1. 알바생 근무 정보 입력 (근무 조, 시급, 시간 등)
2. 세전 총 급여 계산
3. 세금 공제 및 최종 실수령액 산정
4. 주휴수당 및 야간수당 조건 판별(향후 구현)
5. 급여 명세서 전체 출력
6. 프로그램 종료

# 🚀 [버전별 개발 일지 & AI 협업 기록]

## 🟦 [1차 과제: V1.0] 기초 뼈대 구축 (입출력과 변수)
### **✨V1.0 개발 내용:**
1. 사용자로부터 근무 조(문자), 시급/일한 시간(정수), 세율(실수)을 입력받아 세전 급여와 세후 실수령액을 계산하여 출력합니다.
2. 각 데이터의 특성에 맞는 4가지 자료형(char, int, float, double)을 혼합 사용하여 입력받는 화면을 구현했습니다.
3. 사칙연산(*, -)을 활용해 '세전 총액'과 '최종 실수령액'을 순차적으로 계산하여 출력했습니다.
    
### **🤖 AI 파트너십 과정**
1. **내용 1
- *프롬프트 요약 : C언어 기초 과제(조건문/반복문 없이 순차 구조만 사용)로 알바비 계산 프로그램을 만들건데 필수조건(변수 5개 이상, 자료형 3개 이상 혼합)을 충족하는 변수 구성 추천 요청
- *적용 내용 : AI의 추천을 받아 char(근무 조), int(시급, 일한 시간, 세전 급여), float, double(세율, 실수령액) 등 4가지 자료형과 6개의 변수를 논리적으로 설계하여 과제 필수 요건을 완벽하게 충족하는 초기 데이터 구조를 확립함.

2. **내용 2
- *프롬프트 요약 : 설계한 변수들을 활용해 scanf를 어디에, 어떻게 배치해야 하는지 시나리오 흐름과 전체 코드의 뼈대 구성 요청
-  *적용 내용 : 변수 선언 ➔ printf/scanf를 세트로 묶은 데이터 입력 ➔ 산술 연산 ➔ 최종 출력으로 이어지는 완벽한 순차 구조의 로직을 이해하고, 프로그램의 뼈대를 성공적으로 구축함.

    
### **🛠️ Troubleshooting & 기술 회고:**
  1. **문제 1:** scanf 함수 사용 시 변수에 값을 저장하는 정확한 문법적 이해 부족.
     * **해결:** 예시 코드를 통해 scanf 사용 시 변수명 앞에 & (주소 연산자) 기호를 반드시 붙여야 한다는 점을 명확히 인지하고, 모든 입력 부분에 올바르게 적용하여 에러를 방지함.
  2. **문제 2:** 변수의 이름들이 쓰기 번거롭고 길어서 오타 발생
     * **해결:** 기존 AI의 도움을 받은 변수이름 말고 다른 변수로 변경해서 사용함.
  3. **문제 3:** printf 구문에 %하나만 쓸 시 오류 발생 
     * **해결:** AI의 도움을 받아 printf 구문에 %를 작성할 시에는 %%두개가 필요하다는 것을 알았음. (강의자료 포함)

## 🟩 [2차 과제: V2.0] 조건 분기 적용 (조건문) - 향후 작성 예정
### **✨2차 과제 업데이트 내용:**
  * 내용.
1.기존 순차 구조 알바비 계산 프로그램에 if조건문을 도입하여 실제 급여 계산과 유사한 '야간조 수당'과 '초과 근무 수당' 계산을 추가하였습니다.
2. 사용자가 야간조를 입력하면 기본급의 50%를 추가 수당으로 산정하고, 월 160시간을 초과 근무한 경우 초과한 시간에 한해 50%의 수당을 가하도록 구현하였습니다.
3. 영수증 출력 시, 기본급과 추가 수당 항목을 분리하여 조건문 통과 여부에 따른 수당 변화를 명확히 확인할 수 있도록 하였습니다.
    
### **🤖 AI 파트너십 과정**
 1. **내용 1**
    * **프롬프트 요약:**
    - 기존 완성된 알바비 계산 코드에 if조건문을 적용하기 적합한 실생활 시나리오 아이디어 추천 및 구현 방법 요청 
    * **적용 내용:**
    - AI가 제안한 여러 시나리오 중 '야간조 특별 수당'과 '초과 근무 수당'을 조합하여 적용함. 조건문 잗성 시 ==, > 등 관계 연산자와 or 논리 연산자를 활용하여 소문자 입력 예외 상황까지 처리할 수 있게 하였다. 또, bonus_salary라는 변수를 새롭게 선언하여 각 if조건을 만족할 때마다 수당이 누적되도록 설계하였다.
    
### **🛠️ Troubleshooting & 기술 회고:**
  1. **문제 1:** 변수가 많아지며 변수 이름이 헷갈리는 문제 발생 
    **해결:** 기존 변수이름을 좀 더 직관적으로 변경 (hours -> work_hours)
  2. **문제 2:** 실행 시 바꾼 변수이름을 적용하지않아 오류 발생 
    **해결:** 바꾼 변수 이름 적용
  3. **문제 3:** 산술연산 수식을 잘못 적용하여 값이 너무 크게 나옴 
    **해결:** 수식 변경
